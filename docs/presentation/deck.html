问题

竞品分析：重复、分散、难追溯

流程重

信息搜集 → 功能对比 → 评价整理 → SWOT → 报告，环节多、重复性高。

来源散

信息源分散，结论常常无法回溯到原始出处，可信度存疑。

不一致

人工产出格式不统一，难以横向对比、难以规模化复用。

易“幻觉”

直接让 LLM 写报告：看似完整，实则无据、不可验证。

方案 · 多 Agent 编排（LangGraph）

四个专职 Agent，DAG 式任务流转

采集 Collector→ 分析 Analyst→ 质检 QA→ 撰写 Writer→ 综合 Synthesis
↺ 质检打回 → 重新采集 / 重新分析（反馈闭环）
  • 职责边界清晰、无重叠；结构化消息传递（Schema/字段对象），非纯自然语言对话。
  • 采集含问卷设计 / 访谈证据通道；质检为确定性规则（不调用 LLM、无注入风险）。

可信度 · 35% 评分轴的核心

无证据不准入 · 每条结论可溯源

引用即原文

片段必须是来源原文的逐字子串（verbatim-or-reject），否则打回。

取值可核实

结构化取值（定价等）必须能在引用来源中逐字核实（VALUE_UNSUPPORTED）。

一键溯源

报告每句话挂引用 chip → 点开即看原始来源 + 高亮原文 + 出处哈希。

确定性 QA 门禁 · LLM 不裁定真值 · 写入器投影不变量（仅通过项进报告）
Every accepted claim is tied to source, verifier, and repair history.
The product refuses unsupported depth instead of hallucinating confidence.
